I've decided to add a little flash chip as well, just for persistent configuration. Just using a cheap wee one from the basic parts. Uses i2c so I can just redo the i2c bus I've already got set up.
![Flash](https://cdn.hackclub.com/019eb8cc-7905-726b-9ff6-402153e15636/paste-1781216867201.png)

I've also just figured that I might need a level shifter for the sdram :( It runs at 1.8V and the fpga runs at 3.3V.

Yep my suspicions were correct, it can only tolerate ~2.4V. There is an easier solution however: Because each bank of the ice40 chip has a seperate vcc, I can just power the spi block at 1.8V.

A problem with this is that the USB interface ic runs at 3.3v, so I've decided to just use two spi sets. The ice40 has two hardware spi interfaces, so I've put one of them on bank 1 at 1.8V for the sdram, and the other on bank 2 at 3.3V for the USB-SPI interface. Pretty chill :)

And after doing a final pass and adding a bunch of test points, I'm happy to call the schematic complete!
